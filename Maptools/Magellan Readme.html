Magellan FTG preview

Restored Magellan map tools with native FTG provinces.txt support and larger province ID ranges. Windows and .NET Framework 4.8 are required.

Keep the tools and DLLs together. mview is a map viewer. Map graphics can be edited through the layered PSD workflow with mimage; a scenario editor is planned separately.

Commands

mextract.exe MyMap.eu2map /D:"C:\Games\For The Glory\Mods\MyMod" /3
mview.exe MyMap.eu2map
mprovince.exe /E MyMap.eu2map provinces.txt /TXT /O
mprovince.exe /I provinces.txt MyMap.eu2map /TXT
mcolor.exe /ID:9999 /C:FTG16

minject writes native files to its selected destination. Use a separate mod copy. FTG supports at most 10000 province slots; the local ID-grid limit remains 255 non-TI IDs per 2048 x 2048 region.

Preview status

Earlier integration runs passed 20 checks. The user reported loading a test scenario with 144 added provinces, IDs 2020-2163, and seeing its island in FTG. A previous startup crash remains unexplained; full-range in-game compatibility is not established.
